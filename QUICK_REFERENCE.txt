Chat Shows:
  ✓ "Controlling the browser..." (while executing)
  ✓ "Navigating to..." (what it's doing)
  ✓ "Page loaded" (success confirmation)
  ✓ Final response (action completed)

Browser Shows:
  ✓ Chrome window opens (separate from overlay)
  ✓ Navigates to correct website
  ✓ Performs search if requested
  ✓ Shows results/content

┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

First Command:    5-10 seconds (Chrome starting)
Later Commands:   1-3 seconds (Chrome already running)
Tab Switching:    Instant (~0.3s, cached)
Search:           2-3 seconds
Screenshot:       1-2 seconds

┃ 🐛 IF SOMETHING'S WRONG                                                   ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

App window missing?     → Press Ctrl+Space to show
Browser didn't open?    → Wait 5-10s (first run is slow)
No response?            → Check internet connection
Command failed?         → Look at error message in chat
Frozen/stuck?           → Close button hides app, Ctrl+Space brings it back

Browser Automation is Working if:
  ✓ Chrome opens on command
  ✓ Navigates to correct URL
  ✓ Performs searches
  ✓ Switches tabs smoothly
  ✓ Takes screenshots
  ✓ Chat confirms actions
  ✓ No flickering
  ✓ Session persists (logins remembered)
